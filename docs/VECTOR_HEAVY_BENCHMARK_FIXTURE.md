# Vector-heavy benchmark fixture

`vector_heavy.pdf` is a deterministic, copyright-free PDF generated by
`scripts/generate_ci_benchmark_corpus.py`. It exercises native vector extraction without adding a
runtime dependency or storing third-party source material.

## Evidence represented

The single-page fixture persists four drawing groups:

1. a stroked and filled rectangle with an internal divider;
2. a dashed cubic Bezier curve;
3. a closed polygon with a translucent fill;
4. concentric circular paths with explicit stroke opacity.

The page also contains deterministic narrative labels so reading-order acceptance does not reward
promoting decorative graphics into document flow.

Generated corpus evidence records both `drawing_count` and `drawing_item_count` after the PDF is
saved and reopened. Focused tests additionally verify fill presence, dash persistence, opacity,
absence of raster images, and stable textual labels.

## Generate and inspect

```bash
python scripts/generate_ci_benchmark_corpus.py artifacts/ci-corpus \
  --evidence artifacts/ci-benchmark/generated-corpus.json

akilan benchmark artifacts/ci-corpus \
  --output-root artifacts/ci-benchmark/artifacts \
  --report artifacts/ci-benchmark/report.json \
  --acceptance-report artifacts/ci-benchmark/acceptance.json \
  --min-ordered-element-ratio 0.75 \
  --no-cache
```

The fixture remains additive to the benchmark corpus and does not alter the canonical artifact
schema. PyMuPDF remains the only runtime dependency.
